Bili 4K 拉流 · pili:// 协议安装包（Windows 10/11）
========================================================================

这个包做什么
    让网页/扩展能通过 pili:// 打开本机播放器。装好后，在 B 站视频页点扩展的
    「打开 mpv 播放 / 直连播放（mpv）」就能直接播放高画质。

一、安装（3 步）
    1. 把整个文件夹解压到一个固定位置，例如 D:\Tools\pili-protocol。
       不要只复制其中一个文件；装完后这个文件夹可以留着，也可以删（脚本已复制到
       本机 %LOCALAPPDATA%\pili4k\bin）。
    2. 如果还没装 mpv，先看下面第二节；没有 mpv 也能装协议，只是直连播放会失败。
    3. 双击「安装.cmd」，等窗口出现「结论：安装成功」。
       如果出现 [FAIL]，直接把整个窗口截图发回来即可。
       如果双击时 Windows 弹「安全警告 / 打开文件」，点「运行」——这是下载文件的常规提示。

    安装不需要管理员权限：只写当前用户注册表 HKCU\Software\Classes\pili，
    不改系统目录，不会弹 UAC。

二、mpv 装在哪
    任选一种：
      - 命令行：winget install mpv
      - 命令行：scoop install mpv
      - 官网下载压缩包，解压到任意目录（例如 D:\Tools\mpv）
    安装脚本会自动在这些地方找：环境变量 BILI4K_MPV、PATH、Program Files、
    Program Files (x86)、%LOCALAPPDATA%\Programs、scoop、winget、chocolatey。

    如果你的 mpv 在别处，设置环境变量：
        BILI4K_MPV = D:\Tools\mpv\mpv.exe
    然后双击「自检.cmd」重新检查。
    安装脚本找到 mpv 后还会把路径写进 %LOCALAPPDATA%\pili4k\mpv-path.txt，
    播放时优先读这个文件（环境变量没生效也能用）。

三、怎么用
    在浏览器装好扩展、填好后端地址后，打开 B 站视频页，点扩展面板里的
    「打开 mpv 播放」（收起态胶囊）或「直连播放（mpv）」（展开面板）。
    地址栏输入 pili://check 回车，也可以做一次快速自检（不会弹播放器）。

四、出问题看哪里
    - 先双击「自检.cmd」，它会把每一项的结果和结论直接打在窗口里，截图最方便。
    - 详细日志：%LOCALAPPDATA%\pili4k\play.log
      mpv 自己的日志：同目录的 mpv.log
    - 如果窗口提示「调用链不通」：多半是 PowerShell 执行策略或杀毒软件拦截，
      把安装包目录加入信任后再试。

五、卸载
    双击「卸载.cmd」，输入 y 回车。
    会删除 HKCU\Software\Classes\pili 和 %LOCALAPPDATA%\pili4k\bin。
    日志目录 %LOCALAPPDATA%\pili4k 会保留，确认不需要后可手动删除。

六、常见问题
    [FAIL] 调用链不通
        杀软拦截 powershell.exe / wscript.exe；或组策略禁用了脚本执行。
    [WARN] mpv 找到但打不开
        装 VC++ 2015-2022 x64 运行库；确认系统位数与 mpv 位数一致；
        在命令行手动运行 "mpv --version" 看具体报错。
    [WARN] 没有找到 mpv
        按第二节安装，或设置 BILI4K_MPV 后重跑「自检.cmd」。
    自检全是 [OK]，但点播放弹「未找到 mpv」
        环境变量是设置那一刻的快照；浏览器比它启动得早，就继承不到。
        依次试：① 完全退出浏览器再打开，或重启电脑；② 重新双击「安装.cmd」；
        ③ 手动在 %LOCALAPPDATA%\pili4k\ 下新建 mpv-path.txt，一行写 mpv.exe 完整路径。
    PotPlayer 代理模式
        不受 mpv 影响；只要后端和网络正常就能用。
